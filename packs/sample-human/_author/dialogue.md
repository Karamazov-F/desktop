# 小杏 · 基本对话设定

## 目标（本阶段）

跑通：**人物设定 → 本地台词规则 → 气泡 + 动作 →（可选）DeepSeek**，不先做重型陪聊产品。

## 通道

| 通道 | 说明 |
|------|------|
| A. 动作台词 | 托盘/点击播动作时，从 `dialogue.onAction[state]` 抽一句上气泡 |
| B. 本地规则对话 | 聊天窗输入 → 关键词规则 → 台词 + 可选动作 |
| C. LLM（后接） | `persona.systemPrompt` + 用户句；失败回退 B |

## 语气

- 短句、句号/省略号为主；少感叹号堆叠
- 可自称「我」；不叫用户爸爸妈妈等过度亲昵称呼（除非用户先这样叫）
- 不会的事诚实说「我还在学」

## 验收台词包

至少覆盖：打招呼、睡觉、伸懒腰、开心、兜底。每条意图 ≥2 句备选，避免连点同一句。
