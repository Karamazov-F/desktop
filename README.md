# 桌宠

一只待在桌面上的小鲸。可以拖动、点击、对话，也可以按住说话。

## 开始使用（Windows）

需要 Node.js 18 或更新版本。

```powershell
cd app
npm install
npm start
```

第一次启动会检查语音所需的 Node、FFmpeg、sherpa-onnx 和 SenseVoice-Small。缺的可以在弹出的窗口里点「一键安装缺失项」，文件会下到本机，不改系统设置。

DeepSeek 用来文字聊天。在托盘「设置…」里粘贴 API Key 并打开开关。没有 Key 时，仍可以用角色自己的台词。

## 怎么互动

- 悬停小人：脚下出现对话药丸。移开后会收起。
- 单击：做一个动作。
- 按住并拖动：挪位置。
- 双击：打开输入框。
- 右键：菜单（碎碎念、对话、动作）。
- 输入框里有字时，右侧发送按钮会亮起来。
- 按住麦克风超过半秒再松开，会把说的话发出去。按得太短会在身上飘一句提示，不会发送。
- 点输入框和小人以外的地方，输入框会收起，这一下仍然点在你点的位置上。
- 托盘「聊天记录…」打开独立的记录窗口。
- 默认快捷键：`Ctrl+Shift+空格` 语音，`Ctrl+Shift+H` 隐藏或显示。都可以在设置里改。

首次启动会尝试在桌面放一个「桌宠」快捷方式。

## 声明

截屏感知默认关闭。打开后，桌面画面会发到你填写的视觉接口，可以随时关掉。
