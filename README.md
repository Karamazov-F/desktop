# 桌宠

一只待在桌面上的小鲸。可以拖动、点击、对话，也可以按住说话。

## 安装（Windows）

1. 下载 `桌宠-Setup-*.exe`。
2. 双击安装。安装程序会在桌面和开始菜单放上「桌宠」快捷方式。
3. 打开桌宠即可使用。不需要再安装 Node.js、Python 或其他软件，也不会在第一次打开时下载语音模型。

卸载时，安装程序会询问要不要一并删除本机的设置、聊天记录和记忆。

## 怎么互动

- 悬停小人：脚下出现对话药丸。移开后会收起。
- 单击：做一个动作。
- 按住并拖动：挪位置。
- 双击：打开输入框。
- 右键：菜单（碎碎念、对话、动作）。
- 输入框里有字时，右侧发送按钮会亮起来。
- 按住麦克风超过半秒再松开，会把说的话发出去。按得太短会在身上飘一句提示，不会发送。
- 点输入框和小人以外的地方，输入框会收起，这一下仍然点在你点的位置上。
- 托盘「聊天记录…」打开独立的记录窗口。
- 默认快捷键：`Ctrl+Shift+空格` 语音，`Ctrl+Shift+H` 隐藏或显示。都可以在设置里改。

DeepSeek 用来文字聊天。在托盘「设置…」里粘贴 API Key 并打开开关。没有 Key 时，仍可以用角色自己的台词。Key 用 Windows 系统加密保存在本机。

## 隐私

首次打开会看到一份说明。简要版本：

- 文字对话会把你输入的内容、角色设定，以及（若打开「记住对话」）本机记忆，发送到 DeepSeek（默认 `https://api.deepseek.com`）。
- 「允许查看屏幕」默认关闭。打开后，只有你让它看屏幕时才会截图，画面上会有提示，截图发给视觉接口。碎碎念不会截屏。
- 语音在本机识别，录音不会上传。
- 聊天记录（最多最近 100 条）、记忆和设置在 `%APPDATA%\desktop-pet`。设置里可以一键「清除全部聊天记录和记忆」。

## 角色包

可以在设置里导入别人给你的 `.dpet` 或角色文件夹。请只导入你信任的包。
