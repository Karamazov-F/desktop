# 02 · 系统托盘

托盘是桌宠的总控入口：换角色、导入包、开各窗口、退出都在这里。

> 托盘菜单是 Windows 原生菜单，无法用 `capturePage` 截图；本篇按 `app/main/tray.js` `rebuildTrayMenu()` 的声明式模板逐条记录。

## 托盘图标

- 图标：`app/tray.png`；文件缺失时降级用 `packs/blob/sprites/idle.png`
- 悬停 tooltip：当前角色显示名（如「小鲸」）
- **左键单击**：若宠物处于隐藏状态 → 显示宠物；否则 → 打开[对话输入浮窗](04-compose.md)

## 右键菜单（逐条）

| 菜单项 | 行为 |
|--|--|
| 对话 / 输入 | 打开[对话输入浮窗](04-compose.md) |
| 聊天记录… | 打开[聊天记录窗口](05-chat-history.md) |
| 语音（`Ctrl + Shift + 空格`） | 开始/结束语音输入（热键显示随设置变化；当前机器改为 `` Ctrl + ` ``） |
| 隐藏小人（勿扰 · `Ctrl + Shift + H`） | 隐藏宠物；隐藏时此项变为「显示小人（`Ctrl + Shift + H`）」 |
| ── 分隔线 ── | |
| 导入角色包… | 文件对话框选 `.dpet`；成功则解密导入、立即切换为该角色并弹「已导入 <名称>（<id>）」；失败弹错误框 |
| 角色 ▸ | 子菜单列出全部包（自带 `packs/` + 已导入），当前包名前带 `✓`；点击即切换并即时调整窗口尺寸 |
| 动作 ▸ | 子菜单：「待机」+ 当前包全部动作（显示名取包内 `label`，缺省查内置中文表，再缺省显示动作 id）；点击播一次并配包内台词 |
| 朝向 ▸ | 「朝右（不翻转）」/「朝左（水平翻转）」 |
| ── 分隔线 ── | |
| 设置… | 打开[设置窗口](06-settings.md) |
| 环境依赖… | 打开[环境依赖窗口](07-setup-deps.md) |
| ── 分隔线 ── | |
| 退出 | 退出应用（注销全部全局热键、关闭语音识别子进程） |

## 实时性

以下操作后菜单立即重建：切换角色、保存设置（热键/隐藏状态文案随之更新）、导入包。

## 代码位置

`app/main/tray.js`：`buildTray`（图标 + 左键）、`rebuildTrayMenu`（菜单模板）。导入对话框在 `app/main/windows.js` `importPackDialog`。
