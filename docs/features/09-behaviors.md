# 09 · 行为与自动化（非界面功能）

本篇记录不对应单一窗口的功能：生命流、AI 对话、记忆、语音、截屏感知、热键等。默认值见[设置篇](06-settings.md)。

## 待机与生命流（`app/lib/behavior.js` + `pet.js`）

- **待机循环**：`idle` 循环播放，支持乒乓回放（`pingpong`）；空闲 2.5–5s 随机眨眼（45%）或打盹（35%，4–7s 后醒）
- **生命流**（设置「自己过日子」，默认关）：加权随机决定下一步——待机 30 / 转身 10 / 小动作 32 / 休息 8 / 移动 20（无对应动作的包自动把权重归零并归一化）
  - 移动 = 沿当前朝向水平游走 90–230px，1.6–2.3s 缓动完成；离工作区边缘不足 56px 时先转身
  - 连续两次小动作不相同（avoidRepeat）
  - 系统开启「减少动态」时：不平移，瞬移到位
  - 拖动中、输入浮窗开着时暂停生命流
- **朝向**：朝左 = 行走帧水平翻转（`scaleX(-1)`），不需要额外的左向素材

## 全屏隐藏（`app/main/boot.js` 3 秒轮询）

- **全屏隐藏**：检测到主屏工作区 == 屏幕尺寸（全屏应用）→ 隐藏宠物；退出全屏自动恢复

## 新手引导（只发一次）

首次启动（`onboarded` 为假）后连发三条气泡：0.8s「点我会挥手；按住拖我。打字用托盘或右键。」→ 3.5s 语音热键提示 → 7s 隐藏热键提示；然后置 `onboarded=true`。

## AI 对话（`app/lib/agent.js`）

**降级链**：DeepSeek 开且有 Key → 走模型；否则 / 调用失败 → 角色包本地规则；永远有回复。

**工具白名单**（主进程逐一校验后才执行，无任意 shell）：

| 工具 | 何时可用 | 行为 |
|--|--|--|
| `play_action` | 始终 | 播包内动作 id（不存在则拒绝） |
| `move_pet` | 始终 | 边播行走动画边平移窗口；方向限 left/right/up/down，距离夹在 40–900px |
| `remember` | 记忆开 | 写入一条用户事实（≤240 字，去重） |
| `forget` | 记忆开 | 按关键词删除记忆 |
| `glance_screen` | 截屏感知开 | 截主屏 → 视觉模型描述 → 作为工具结果回给文本模型 |

每轮对话最多 5 次工具循环；回复上限 400 token；单条输入截 2000 字；会话历史保留最近 16 条（仅内存，重启清空）。

**本地规则引擎**（`app/lib/dialogue.js`）：按包内 `dialogue.rules` 关键词匹配（小写关键词走不区分大小写匹配）；内置走路意图正则（走/过来/走开/散步… + 方向词推断 left/right/up/down），无 DeepSeek 也能「往左走」。

## 长期记忆（`app/lib/memory.js`）

- 默认关；按角色分文件存 `%APPDATA%\…\memory\<packId>.json`
- facts 上限 80 条；每轮对话后自动把「用户：…/宠：…」摘要追加进 summary（整体截 1200 字）
- 设置页「清空记忆」只清当前角色

## 截屏感知（`app/lib/vision.js`）

- 默认关；只在用户问屏幕内容时由模型主动调 `glance_screen`
- 截屏前先把宠物窗口藏起来 80ms（防止自拍），截完恢复
- 截图缩到 ≤1280×720、JPEG 70% 质量；提示词要求「不超过 80 字、笼统描述、不猜隐私细节」

## 语音（`app/lib/stt.js` + `workers/sherpa-stt-worker.js`）

- 链路：MediaRecorder（webm/opus）→ FFmpeg 转 16kHz 单声道 WAV → sherpa-onnx + SenseVoice-Small **本地识别**（独立 Node 子进程，JSON-lines 协议，崩溃自动重启）
- 触发：[设置热键](06-settings.md)按一下开始、再按一下结束；或[输入坞药丸](04-compose.md)的麦克风 / 展开输入框左侧麦克风 / 聊天窗「说话」按钮**按住说话、松开结束**
- 反馈是状态驱动的：`voice-state` 广播到宠物（听录呼吸点）、聊天窗、输入坞（麦克风变红）三路；热键发起时药丸自动出现亮红麦（不抢焦点），整个周期钉住不被悬停/失焦关闭，结束（`idle`）自动收起——录音不会卡死、红点不会常亮
- 录音 <200 字节视为太短直接丢弃；识别出的文字自动发送给角色
- 录音中：宠物窗右下角红点 + 按钮变「听…/识别」
- 缺依赖（sherpa/sensevoice）时语音不可用，其余功能不受影响；依赖装齐后启动自动预热识别进程

## 热键（`app/lib/hotkeys.js`）

- 默认：语音 `Ctrl+Shift+空格`，隐藏/显示 `Ctrl+Shift+H`（当前机器实拍为 `` Ctrl+` `` / `Ctrl+Shift+H`）
- 全局生效；注册失败（被占用）在设置保存时明示；两个热键不允许相同
- 捕获规则：至少一个修饰键；F1–F24 可单用；`Esc` 取消录入；`Backspace/Delete` 清除

## 聊天记录（`app/lib/chat-log.js`）

- 按角色分文件，只留最近 20 条，单条截 2000 字
- 浮窗、聊天窗、语音三路产生的对话都进同一份记录
